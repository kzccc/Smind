# 可缩放粘贴图片设计

## 目标

让右侧节点详情编辑器中的粘贴图片支持选中和拖拽缩放，并把缩放后的尺寸随项目保存和恢复。

## 交互

- 点击图片时选中图片，并显示蓝色选中边框和右下角缩放手柄。
- 拖动右下角手柄时按原始宽高比同步调整宽高。
- 图片不能小于 48px，也不能超过编辑器可用宽度。
- 点击文字、编辑器空白处或切换节点时取消图片选中。
- 图片缩放属于详情编辑器操作，`Ctrl+Z` 可以撤销最近一次缩放。

## 数据与安全

- 图片仍以内嵌 `data:image/...;base64,...` 保存。
- 图片尺寸写入清洗后的 `<img width="..." height="...">` 属性。
- 只接受正整数尺寸，清洗时限制在 48 到 1600 像素。
- 非 Data URL 图片以及不安全属性继续被清除。

## 测试

- 浏览器测试粘贴 1x1 PNG 后选中图片。
- 模拟拖动缩放手柄，验证宽高改变且比例保持。
- 等待自动保存，验证 `detailHtml` 含尺寸属性。
- 切换节点再切回，验证图片尺寸仍然存在。
- 保持现有逻辑、快捷键、存储和性能测试通过。
